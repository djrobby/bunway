# Bunway application

This is ordinary Elysia, Drizzle, Eden Treaty, and SvelteKit code generated by Bunway.

Realtime channels use `channel()` and the included `realtimeRoutes`. Generate a recipe with
`bunway g realtime status Order` or `bunway g realtime chat Room`.

```powershell
Copy-Item .env.example .env
bunway db:migrate
bunway dev
```

The default `db` export is the named `primary` PostgreSQL connection. Add another with
`bunway db:add <name> --adapter=postgres|mysql|sqlite|pocketbase`.

The API defaults to `http://localhost:3000`; the SvelteKit UI URL is printed by Vite and normally defaults to `http://localhost:5173`. Environment variables are loaded when the process starts, so restart `bunway dev` after changing `.env`.

Use Bun for all package and script operations. Generate a full stack with `bunway g scaffold Product name:string price:decimal`, an API with `bunway g resource Product name:string`, a schema with `bunway g model User email:string:unique`, or a job with `bunway g job ImportProducts`.

Relationships support `references`/`belongs_to`, `has_one`, `has_many`, and `many_to_many`. Generate related resources first, then use fields such as `author:belongs_to`, `profile:has_one:optional`, `comments:has_many`, or `tags:many_to_many`.
